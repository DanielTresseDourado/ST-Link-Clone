# ST-Link Clone

Projeto desenvolvido na disciplina de Prototipagem do curso de Engenharia Elétrica da Universidade Estadual de Londrina (UEL).

Este repositório contém o desenvolvimento de uma placa compatível com o ST-Link para programação e depuração de microcontroladores STM32. O projeto foi concebido com foco na miniaturização do hardware e no desenvolvimento de uma PCB de alta densidade, empregando um encapsulamento Micro BGA e uma estrutura de seis camadas para atender aos requisitos de roteamento e integridade dos sinais.

## Conteúdo do repositório

- Projeto completo do Altium Designer
- Arquivos do projeto (.PrjPcb)
- Esquemáticos (.SchDoc)
- Layout da PCB (.PcbDoc)
- Bibliotecas de componentes esquemáticos e de PCB
- Arquivos de fabricação (Gerbers)

## Características

- Compatível com ST-Link para programação e depuração de microcontroladores STM32
- PCB de seis camadas
- Layout de alta densidade (HDI)
- Encapsulamento Micro BGA
- Formato compacto, com dimensões próximas às de um dongle USB
- Projeto desenvolvido no Altium Designer
- Documentação completa para edição e fabricação
